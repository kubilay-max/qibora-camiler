# Qibora – cami verisi

Qibora ve Miswak uygulamalarının "en yakın camiler" özelliği için dünya genelindeki camilerin
1°×1° karelere bölünmüş verisi. Her ay GitHub Actions ile OpenStreetMap'ten otomatik güncellenir.

- `t/<enlem>_<boylam>.json` — karedeki camiler: `[enlem, boylam, "ad", {"dil": "ad"}]`
- `bilgi.json` — son güncelleme tarihi ve sayılar
